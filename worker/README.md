# 오늘의 마음 — 우체국 (선택 사항)

이 폴더는 **없어도 앱이 돌아갑니다.** 지금처럼 링크를 카톡으로 직접 보내는 방식은 그대로 작동하고,
우체국을 연결하면 네 가지가 추가로 열립니다.

| 기능 | 설명 |
|---|---|
| 🔥 타버리는 편지 | 한 번 열면 서버에서 영구 삭제 |
| 📬 등기우편 | 상대가 봉투를 연 시각이 보낸 사람에게 표시 |
| 🌅 새벽 우편 | 지정한 시각이 되어야 배달 (서버가 지키므로 폰 시계를 돌려도 못 엶) |
| 🕯️ 촛불 | 둘 다 앱을 열고 있으면 서로에게 표시 |

덤으로 링크가 아주 짧아집니다 (`#p=abc123` 형태).

## 프라이버시

서버에는 **암호문만** 올라갑니다. PIN은 기기 밖으로 나가지 않고 복호화는 전부 브라우저에서 일어나므로,
서버를 운영하는 사람도 편지 내용을 볼 수 없습니다. '우리 코드'도 SHA-256 해시만 전송됩니다.

## 배포 (5분, 무료)

Cloudflare 계정이 필요합니다 (무료 플랜으로 충분 — 하루 10만 요청).

```bash
cd worker
npx wrangler login
npx wrangler kv namespace create MAIL
```

마지막 명령이 출력한 `id = "..."` 값을 `wrangler.toml`의 `PUT_YOUR_KV_ID_HERE` 자리에 붙여넣고:

```bash
npx wrangler deploy
```

`https://today-card-post-office.<계정>.workers.dev` 주소가 나오면,
앱 하단 **📮 우체국 연결**에 그 주소를 넣으면 끝입니다.

## 로컬에서 먼저 시험해보기

```bash
npx wrangler dev --port 8787
```

앱의 우체국 주소에 `http://127.0.0.1:8787` 을 넣으면 로그인 없이 동작을 확인할 수 있습니다.
